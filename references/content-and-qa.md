# 内容组织与验收

用于长篇研究论文、综述、指南、多代理协作或对完整性有疑问的任务。轻量局部修订不必重建全部数据结构。

## 推荐的数据边界

让译文数据独立于排版代码。可以沿用现有项目的 JSON/TeX/Markdown，而不是为了本技能强行迁移。若新建中间格式，可采用以下字段：

| 对象 | 有用字段 | 要防的丢失 |
|---|---|---|
| metadata | source_file, source_version, title_en/zh, authors, affiliations, journal, year, volume, issue, pages_or_article, doi, online_date | 不同版本的元数据互相混用 |
| blocks | id, type, heading_path, source_pages, text_zh, continuation_from | 跨页续句重译两次或前后都遗漏 |
| figures/tables | id, source_page, panels, caption_zh, labels_zh, notes_zh, asset_path, crop_box | 图注尾句、面板字母、表脚注、图中统计符号 |
| references | id, original_text, doi, pmid, annotation_zh | Nature 评注混入英文条目、跨页书目断开 |
| backmatter | type, source_pages, text_zh | 经费编号、贡献声明、冲突/数据/许可说明 |
| coverage | source_id, output_id, status, reason | 把未提供的补充材料标为已完成 |

用源文定位作为稳定 ID；不要仅依靠中文版页号，中文重排会改变页码。多代理分工给出准确章节边界和首尾续句，统一术语后合并。合并前后保留文本哈希，发现差异回到对应源段核对。

## 源文忠实性

- 覆盖源文件实际提供的内容，不仅是从引言到讨论。独立研究摘要页、主文摘要、完整方法、编辑摘要可能内容相近但仍是不同部分。
- 参考文献保持原文，去掉排版断行、错误软连字符等抽取噪声时不得改变作者、题名、出版信息或编号。DOI/PMID 可转成链接，但缺项不补造。
- 术语首次出现时可中文后附英文/缩写；后续统一。基因、蛋白、细胞群标签不随意互换；人/鼠命名大小写、上/下标和阳性/阴性标记保留。
- 核对高风险数字：样本量、剂量、时间轴、比例、阈值、区间开闭端、P 值、统计方法、序列和试剂标识。数值相同不等于语义相同，须核对比较方向与对象。
- 原文的数值/图文矛盾可保留并在译注中说明；明确字符识别错误应对照页面修正。将“原文如此”和“译者核订”分清，不通过外部常识静默改写。
- 指南还要逐项覆盖推荐表、推荐类别和证据等级、定义、算法框、警示与表脚注；不要仅翻译解释性正文，也不把翻译变成面向个人的治疗建议。

## 图表与下载标记

记录每幅图的物理页、坐标约定和全部面板。PDF 通常左下原点，图像/页面工具常用左上原点；坐标转换应依据实际页面框和旋转状态。检查裁图后没有残余正文、截断标签或旁栏标记。

保留原图时完整翻译图注，并提供图内非专有名词的对应释义；若数据图很密集，按面板 A/B/C 分组放附录比挤进图内更稳妥，但须让用户知道图内英文尚保留。真正替换图内文本时不能改变坐标、误差线、显著性标记、颜色对应或量尺。

清除下载标记只针对识别出的下载来源层。不要删除作者单位中相同的机构名，不要把科学数据中外观类似 IP 的数字当作标记。清理后渲染边缘区域，同时扫描嵌套对象与提取文本；无法可靠分离时换用局部图形处理并再次核对，不做全页粗糙遮挡。

## 自动检查的用法与边界

`scripts/audit_pdf.py --help` 列出实际参数。脚本需要 Python 3.10+ 和 `pypdf`，优先使用环境已有的运行时。典型调用（期望数量来自当前原文）：

```text
python audit_pdf.py final.pdf --forbidden-text "Downloaded from" --expected-ref-count 79 --ref-prefix "ref:" --tex-log build/final.log --output audit.json
```

这里的 79 只是用法演示，不能在其他文章中固定采用。工具报告明确词条残留、引文目标/跳转及编译问题，不能判断英文标签是否已翻译、未知水印是否存在、论文事实是否正确。用户的机构/IP等完整下载文字不要放进共享技能或公开日志。

文字完整性检查应按双栏阅读顺序重构，或逐块定位。原图会携带英文文字，整页提取也可能把左右栏交错；不能把抽取错序直接当作漏译。归一化只处理空白、换行、排版连字符等非语义差异，勿吞掉正负号、小数点或上下标。核对每个源段均映射到输出；预期重复（如摘要、版权说明）显式记录，而不是一律删除。

## 最终检查

1. 所有实际源内容有对应译文；没有未说明的占位内容或缺失附件。
2. 原始研究数值、推荐等级、公式与编号完整，书目顺序和引用关系正确。
3. 每页渲染可读，无缺字、越界、遮挡、截断图注、意外空页和漂移到书目后的正文图。
4. 页眉页脚保留合适的出版身份信息，下载来源层已按用户要求排除；非官方中文译稿和独立页码清楚。
5. 新建或完整重排稿以完整原文信息结束，链接可识别，原文件未被覆盖；仅删框等局部修订不额外扩大修改范围。
6. 可编辑源包白名单与最终 PDF 匹配，检查 ZIP 完整性及必要文件哈希；不混入旧 PDF、原始下载标记、原论文全文或机器特定路径。

对于“只改一个框”等小修改，只检查受影响的结构和页面，并证明其余内容保持；已通过的科学内容不必反复重审。
