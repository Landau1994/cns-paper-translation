# 五套中性XeLaTeX模板

这组模板从已核验的五篇文章版本提炼结构，不代表期刊的完整官方版式标准。模板只包含原创中性文字与TikZ矢量占位图；所有作者、出版信息和参考文献均明确标为示例。不得把示例条目直接作为真实论文信息使用。

| 入口 | 示范结构 | 引文 | 示例页数 |
|---|---|---|---:|
| `cell.tex` | 全宽题名/蓝色摘要、双栏正文、左宽图右窄注 | 蓝色作者-年份 | 2 |
| `nature.tex` | 黑白细线、全宽题名、约1:2元数据/摘要区 | 数字上标 | 2 |
| `science.tex` | 独立四段研究摘要页、主文新页、红学科标记 | 蓝色斜体括号数字 | 3 |
| `immunity.tex` | 蓝刊头/摘要、双栏正文、跨栏图与图注 | 蓝色数字上标 | 2 |
| `nature-reviews-cardiology.tex` | 紫顶线、独立摘要目录页、双栏、跨页表重复标题与列头 | 蓝色数字上标 | 4 |

`common.tex`负责字体回退、共享依赖及原创占位图，`sample-body.tex`提供演示文字。`profiles.json`记录各模板的真实来源版本、纸张、边距、字号及有意改编的部分。复制使用时需把这两个共享TeX文件一并复制。

在本目录运行两次，例如：

```text
xelatex -interaction=nonstopmode -halt-on-error "-output-directory=../previews" cell.tex
```

也可不设置输出目录，直接在模板所在目录编译。需要XeLaTeX、ctex、TikZ、balance、etoolbox及常见TeX Live宏包。中文优先使用已安装的Noto CJK字体，否则回退至TeX Live自带Fandol；拉丁文字使用TeX Gyre字体，无需复制Windows专有字体。Fandol可能产生两条不支持OpenType CJK脚本特性的fontspec提示；本次回退编译无缺字。字体不同会改变断行，因此换机后仍需重新渲染检查。

每套包含题名、摘要、正文层级、原创矢量图、完整演示图注、可跳转占位参考文献及最后的原文信息。页脚使用独立中文译页，刊名仅以普通文字显示，没有复制期刊logo。源文章的下载来源、机构、IP或下载日期均未纳入模板。

完整论文通常不应使用示例中的人工分页：它们仅用于把样板控制在2至4页并展示关键结构。演示页启用双栏平衡；用于长文时可在正常连续正文前调用`\nobalance`，在末页第一栏中调用`\balance`。共享文件为balance旧版补足实际测得的最后一行深度，没有屏蔽越界警告。请根据目标原文结构和中文长度安排浮动图表、连续书目及文末资料，并检查所有图注和书目均完整落版。

Nature Reviews Cardiology 的跨页表使用 `longtable`，需先切到单栏；续页标题与列头由 `\endfirsthead` / `\endhead` 指定。20行中性占位用于确保演示真实跨页，不是论文的固定行数。栏目宽度的总和还需加上单元格留白与竖线宽度，不能仅按正文宽度分配 `p{}`。正式长表应完整翻译每行、分组和脚注，中文重排可增加页数。
